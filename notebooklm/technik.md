# Prüfungstechnik, Operatoren, Englisch

> Quelle für NotebookLM. Thema der IHK-Abschlussprüfung Teil 2, Fachinformatiker Anwendungsentwicklung (Prüfungskatalog 2025), Bereich GA1 Planen.

**Prompt für die Video- oder Audio-Übersicht:** Erkläre dieses Thema für einen Prüfling, der am 25.11.2026 die schriftliche AP2 schreibt. Schnell, klar, mit einem durchgehenden Praxisbeispiel aus einer Steuerberatungskanzlei. Betone typische Prüfungsfehler und zeige, wie eine volle-Punkte-Antwort aussieht. Maximal 8 Minuten.

## Warum prüfungsrelevant

Viele Punkte gehen nicht durch Unwissen verloren, sondern durch falsch gelesene Operatoren, schlechtes Zeitmanagement und leere Felder.

## Inhalt

### 1. Technik bringt Punkte

Viele verlieren Punkte nicht durch Unwissen, sondern durch Technik. Am 25. November 2026 ist die schriftliche Prüfung. GA1 und GA2 dauern je 90 Minuten, WiSo 60. Üblich sind 4 Aufgaben mit je 25 Punkten, ohne Abwahl. Garantiert ist das nicht. 90 Minuten für 100 Punkte, das sind rund 0,9 Minuten pro Punkt. Eine 25-Punkte-Aufgabe bekommt also etwa 22 Minuten. Erst alles überfliegen, Zeit planen, und nichts leer lassen. Stichworte bringen oft noch Teilpunkte. Ein Tipp vorab: Lies jede Aufgabe zweimal und unterstreiche den Operator und die geforderte Anzahl. Das kostet zehn Sekunden und spart dir viele Punkte.

**Merk dir:** Viele Punkte gehen durch Technik verloren, nicht durch Unwissen.

```
Mi, 25.11.2026: schriftliche AP2 Teil 2
GA1   90 Minuten   meist 4 x 25 Punkte
GA2   90 Minuten   meist 4 x 25 Punkte
WiSo  60 Minuten
Abwahl von Aufgaben: üblich keine

90 Minuten / 100 Punkte
= ca. 0,9 Minuten pro Punkt
25-Punkte-Aufgabe: ca. 22 Minuten

1. Erst alles überfliegen
2. Zeit je Aufgabe planen
3. Nichts leer lassen
```

### 2. Operatoren lesen

*Leitfrage: Was bedeuten die Operatoren?*

Nennen heißt: Stichwort reicht. Keine Romane schreiben, das kostet nur Zeit. Beschreiben heißt ganze Sätze. Erläutern und erklären heißt: Aussage plus Begründung oder Beispiel. Begründen fragt nach dem Warum. Vergleichen heißt Gemeinsamkeiten und Unterschiede. Beurteilen und bewerten: Kriterien nennen, abwägen, und am Ende ein klares eigenes Urteil. Beurteilen und bewerten heißt: Du triffst eine eigene, begründete Entscheidung. Eine Aufzählung von Vor- und Nachteilen ohne Fazit reicht dann nicht.

**Merk dir:** Nennen Stichwort, Beschreiben ganze Sätze, Erläutern mit Begründung.

| Operator | Was du lieferst |
|---|---|
| nennen | Stichwort, ohne Erklärung |
| beschreiben | Sachverhalt in ganzen Sätzen |
| erläutern, erklären | Aussage plus Begründung oder Beispiel |
| begründen, vergleichen | Warum, Gemeinsamkeiten, Unterschiede |
| beurteilen, bewerten | eigenes Urteil anhand von Kriterien |

### 3. Zwei heißt zwei

*Leitfrage: Und wenn da steht: Nennen Sie zwei?*

Nennen Sie zwei heißt zwei. Gewertet werden meist die ersten zwei, ein dritter Punkt rettet keinen falschen. Situationsbezug: Nicht allgemein antworten, sondern mit den Fakten aus dem Szenario. Hier die Kanzlei. Entwerfen oder darstellen heißt Modell oder Code liefern. Nutze die Notation aus dem Belegsatz, etwa das SQL-Beiblatt. Situationsbezug heißt: Statt Daten können verloren gehen schreibst du Die Belege der Mandanten könnten verloren gehen. Das zeigt dem Prüfer, dass du den Fall verstanden hast.

**Merk dir:** Zwei heißt zwei. Immer mit Bezug zur Situation antworten.

```
Nennen Sie zwei Vorteile von SaaS.
- keine eigene Wartung
- schnell einsatzbereit
- dritter Punkt: meist nicht gewertet

Erläutern Sie einen Vorteil.
Die Kanzlei spart Wartung, weil der
Anbieter Server und Updates übernimmt.

entwerfen, darstellen: Modell, Code
Notation laut Belegsatz: SQL, UML
Fakten aus dem Szenario übernehmen
```

Kontrollfrage: Nennen Sie drei Ursachen. Du schreibst fünf. Was wird meist gewertet? Antwort: die ersten drei. Gewertet werden meist die ersten genannten, so viele wie verlangt.

### 4. Vokabeln: Projekt

*Leitfrage: Englisch kommt auch dran. Welche Vokabeln brauche ich?*

Englische Texte kommen in GA1 vor. Projekt-Vokabeln zuerst: requirement ist die Anforderung, stakeholder die Beteiligten. Scalability heißt Skalierbarkeit, maintainability Wartbarkeit. Dependency ist eine Abhängigkeit. Deployment ist die Bereitstellung, release die Version. Ein issue ist ein Problem oder Ticket. Englische Aufgaben darfst du meist auf Deutsch beantworten, außer es steht ausdrücklich anders da. Achte genau auf diesen Hinweis.

**Merk dir:** requirement Anforderung, maintainability Wartbarkeit.

```
requirement      Anforderung
stakeholder      Beteiligter, Interessent
feature request  Funktionswunsch
acceptance criteria  Abnahmekriterien
user story       Anforderung aus Nutzersicht
milestone        Meilenstein
scalability      Skalierbarkeit
maintainability  Wartbarkeit
dependency       Abhängigkeit
deployment       Bereitstellung
release          veröffentlichte Version
issue            Problem, Ticket
troubleshooting  Fehlersuche
```

### 5. Vokabeln: Sicherheit, Betrieb

*Leitfrage: Noch mehr Vokabeln?*

Vulnerability ist eine Schwachstelle. Encryption die Verschlüsselung, authentication die Anmeldung mit Identitätsprüfung. Legacy system ist ein Altsystem. Backward compatible heißt abwärtskompatibel. Deprecated heißt veraltet, wird bald entfernt. Patch ist eine Korrektur, rollback das Zurücksetzen, downtime die Ausfallzeit, latency die Verzögerung. Weitere wichtige Wörter: requirement, deployment, availability, reliability. Mach dir eine kleine Vokabelliste und wiederhole sie ein paar Tage lang.

**Merk dir:** vulnerability Schwachstelle, encryption Verschlüsselung.

```
vulnerability    Schwachstelle
encryption       Verschlüsselung
authentication   Authentifizierung
legacy system    Altsystem
backward compatible  abwärtskompatibel
deprecated       veraltet, wird entfernt
patch            Korrektur, Update
rollback         Zurücksetzen
downtime         Ausfallzeit
workaround       Notlösung
latency          Verzögerung
throughput       Durchsatz
```

### 6. Englischen Text knacken

*Leitfrage: Wie knacke ich einen englischen Text?*

Strategie: Erst die Fragen lesen, dann im Text gezielt nach Schlüsselwörtern suchen. Antworte in der Sprache, die die Aufgabe verlangt. Hier: Eine kritische Schwachstelle im Login. Angreifer konnten die Authentifizierung umgehen. Also sofort updaten. Der alte Endpunkt ist veraltet und fliegt mit 4.0 raus. Bestehende Schnittstellen laufen weiter, weil abwärtskompatibel. Und Altsysteme mit Windows Server 2012 werden nicht mehr unterstützt. Unbekannte Wörter überspringst du erst einmal. Oft erklärt der Zusammenhang den Rest, und für die Antwort brauchst du meist nur zwei, drei Sätze aus dem Text.

**Merk dir:** Erst die Fragen lesen, dann gezielt im Text suchen.

```
KanzleiPortal 3.2: Release Notes
This release fixes a critical
vulnerability in the login module.
Attackers could bypass authentication
with a manipulated session token.
We strongly recommend installing this
update immediately. All client documents
are now stored with AES-256 encryption.
The endpoint /api/v1/clients is
deprecated and will be removed in 4.0.
Version 3.2 is backward compatible.
Legacy systems running Windows Server
2012 are no longer supported. Please
report any issues via the support portal.
```

### 7. Bestehen und Gewichtung

*Leitfrage: Und wann habe ich bestanden?*

Gewichtung: AP1 20 Prozent, Projekt 50, GA1, GA2 und WiSo je 10 Prozent. Bestanden bei mindestens 50 Punkten gesamt und in Teil 2, mindestens 50 in drei von vier Bereichen und keinem Bereich unter 30. Mündliche Ergänzungsprüfung auf Antrag in GA1, GA2 oder WiSo, etwa 15 Minuten, wenn sie über das Bestehen entscheiden kann. Gewichtung 2 zu 1: alte Punkte doppelt plus mündliche, geteilt durch 3. Rechne dir mit dem Bestehensrechner in der App aus, wie viele Punkte du in GA1, GA2 und WiSo mindestens brauchst. Das nimmt viel Druck raus.

**Merk dir:** Bestanden: 50 Punkte gesamt und in Teil 2, kein Bereich unter 30.

```
AP1 20, Projekt 50, GA1 10,
GA2 10, WiSo 10 Prozent

Bestanden, wenn
1. Gesamt mind. 50 Punkte
2. Teil 2 mind. 50 Punkte
3. 3 von 4 Bereichen Teil 2 mind. 50
4. kein Bereich in Teil 2 unter 30

Mündliche Ergänzung: auf Antrag,
in GA1, GA2 oder WiSo, ca. 15 Minuten,
nur wenn sie über Bestehen entscheidet
neu = (alt x 2 + mündlich) / 3
```

Kontrollfrage: Schriftlich 40, mündlich 70. Neues Ergebnis? Antwort: 50. 40 mal 2 plus 70 ergibt 150, geteilt durch 3 sind 50.

## Zusammenfassung

Merke: Nennen heißt Stichwort, Beschreiben heißt ganze Sätze, Erläutern heißt mit Begründung. Zwei heißt zwei. Und immer mit Bezug auf die Situation antworten.

## Übungsfragen mit Lösung

1. GA1 dauert 90 Minuten bei 100 Punkten. Wie viele Minuten planst du ungefähr für eine Teilaufgabe mit 12 Punkten ein?
   - Lösung: 10,8. 90 Minuten / 100 Punkte = 0,9 Minuten pro Punkt. 12 x 0,9 = 10,8, also rund 11 Minuten.
2. In der Aufgabe steht: Nennen Sie zwei Vorteile. Du schreibst vier. Was passiert in der Regel?
   - Lösung: Meist werden nur die ersten zwei gewertet. Zwei heißt zwei. Gewertet werden meist die ersten genannten. Ist davon einer falsch, rettet dich ein richtiger dritter nicht.
3. Was verlangt der Operator erläutern?
   - Lösung: eine Aussage mit Begründung oder Beispiel, sodass der Zusammenhang klar wird. Erläutern und erklären = Sachverhalt plus Warum oder Beispiel. Nur ein Stichwort reicht dafür nicht.
4. Was gehört zwingend zu einer Antwort auf beurteilen oder bewerten?
   - Lösung: ein eigenes Urteil, gestützt auf Kriterien. Beurteilen und bewerten = Kriterien nennen, abwägen und am Ende ein klares Urteil fällen.
5. Im Szenario hat die Kanzlei zwei Standorte und speichert Mandantendaten. Du sollst eine Backup-Lösung begründen. Was bringt die meisten Punkte?
   - Lösung: Eine Begründung mit Bezug auf die Kanzlei, etwa zwei Standorte und sensible Mandantendaten. Situationsbezug: Fakten aus dem Szenario übernehmen. Allgemeine Antworten ohne Bezug geben oft nur Teilpunkte.
6. In Release Notes steht: The endpoint /api/v1 is deprecated. Was bedeutet das?
   - Lösung: Er ist veraltet, funktioniert noch, wird aber künftig entfernt. deprecated = veraltet, abgekündigt. Noch nutzbar, aber du solltest umsteigen.
7. Ein Text spricht von a critical vulnerability. Was ist gemeint?
   - Lösung: eine kritische Schwachstelle. vulnerability = Schwachstelle, Sicherheitslücke.
8. Wie gehst du bei einer Aufgabe zu einem englischen Fachtext am besten vor?
   - Lösung: Erst die Fragen lesen, dann im Text gezielt nach Schlüsselwörtern suchen. Fragen zuerst, dann gezielt suchen. Die Antwortsprache steht in der Aufgabenstellung, meist Deutsch.
9. Ergebnisse: AP1 60, Projekt 68, GA1 45, GA2 62, WiSo 70 Punkte. Ist die Prüfung bestanden?
   - Lösung: Ja: Gesamt und Teil 2 mindestens 50, drei von vier Bereichen mindestens 50, keiner unter 30. Teil 2 = (68 x 50 + 45 x 10 + 62 x 10 + 70 x 10) / 80 = ca. 64,6. Gesamt mit AP1 = ca. 63,7. Ein Bereich unter 50 ist erlaubt, solange er nicht unter 30 liegt.
10. Du hast in GA1 28 Punkte, alle anderen Bereiche sind gut. Was gilt?
   - Lösung: Nicht bestanden, weil ein Bereich unter 30 liegt; eine mündliche Ergänzungsprüfung in GA1 kann beantragt werden. Unter 30 = ungenügend, damit nicht bestanden. Die mündliche Ergänzungsprüfung ist möglich, weil sie hier über das Bestehen entscheiden kann.
11. GA1 schriftlich 40 Punkte, mündliche Ergänzungsprüfung 70 Punkte. Wie lautet das neue Ergebnis in GA1 (Gewichtung 2:1)?
   - Lösung: 50. (40 x 2 + 70) / 3 = 150 / 3 = 50 Punkte.
12. Wie stark zählt GA1 im Gesamtergebnis der Abschlussprüfung?
   - Lösung: 10 Prozent. AP1 20 %, Projekt 50 %, GA1 10 %, GA2 10 %, WiSo 10 %.

KanzleiPortal 3.2 Release Notes
This release fixes a critical vulnerability in the login module. Attackers could bypass authentication with a manipulated session token. We strongly recommend installing this update immediately. All client documents are now stored with AES-256 encryption. The endpoint /api/v1/clients is deprecated and will be removed in version 4.0. Version 3.2 is backward compatible, so existing integrations keep working. Legacy systems running Windows Server 2012 are no longer supported. Please report any issues via the support portal.

